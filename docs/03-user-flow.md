# User Flow: 5–10-minütiges Bürgergespräch

Typischer Ablauf, den die App unterstützt (Zeitangaben als grobe
Orientierung für ein Straßengespräch):

1. **Ansprache (0:00–0:30)** — Person auf der Straße ansprechen, iPad
   zeigen. Startbildschirm ist bereits sichtbar (kiosk-artig, kein
   Login nötig).

2. **Einstieg (0:30–1:00)** — Kachel **"Bürgerdialog starten"** antippen.
   Willkommens-Screen erklärt in zwei Sätzen den Zweck, keine
   Registrierung. `[Starten]`.

3. **Neutrale Umfrage (1:00–3:30)**
   - Zufriedenheit mit der politischen Entwicklung (0–10-Skala, ein Tap)
   - Themen, die beschäftigen (Mehrfachauswahl, große Kacheln)
   - Priorität + optionale Begründung (ein Freitextfeld)
   - Vertrauen in Bundesregierung / Bundestag / Polizei & Justiz (3×
     Skala)
   Jeder Schritt: ein Tap zur Auswahl, `[Weiter]`. Zurück-Button jederzeit
   verfügbar.

4. **Ehrlicher Abschluss der Umfrage (3:30–3:45)** — "Danke für deine
   Antworten." Ohne erfundene Prozentzahlen; ein Zwischenstand wird nur
   gezeigt, wenn auf diesem Gerät bereits ausreichend viele Antworten
   vorliegen (Mindeststichprobe, aktuell 20).

5. **Themenwahl (3:45–4:15)** — "Welche Themen möchtest du über die MDP
   kennenlernen?" — 12 Kacheln, Mehrfachauswahl basierend auf dem, was
   die Person gerade genannt hat.

6. **MDP-Positionen zeigen (4:15–7:00)** — Für jedes gewählte Thema eine
   Karte mit der MDP-Position in einem Satz/Zitat. Bei Wohnen /
   Wirtschaft / Infrastruktur zusätzlicher Link zu den vertiefenden
   Konzeptseiten (Wohnungsfonds, Staatliche Industrie,
   Schichtmodell) — nur bei Bedarf/Interesse antippen, kein Zwang.

   *Alternative/Ergänzung:* Statt oder zusätzlich zur Themenwahl kann an
   dieser Stelle **"MDP in 2 Minuten"** gezeigt werden — der komprimierte
   Präsentationsmodus mit 8 großen Kernaussage-Karten, ideal wenn die
   Person wenig Zeit hat oder einen schnellen Gesamtüberblick will.

7. **Fragen beantworten (7:00–9:00)** — Frei navigierbar: zurück zu
   "Themen entdecken" für weitere Themen, oder "Was bedeutet das für
   mich?" für eine an die Lebenssituation angepasste Auswahl (z. B.
   "Ich wohne zur Miete").

8. **Abschluss (9:00–10:00)** — QR-Code-Screen: großer QR-Code zur
   offiziellen Website, Buttons "Website öffnen" / "Programm ansehen" /
   "Mitmachen". Die Person entscheidet selbst, ob sie ihr eigenes
   Smartphone zum Scannen zückt — kein Zwang, kein Datenaustausch vom
   iPad.

## Kurzform (wenig Zeit)

Direkteinstieg über Hauptnav-Kachel **"QR-Code / Website"** oder direkt
**"MDP in 2 Minuten"**, wenn für eine volle Umfrage keine Zeit ist.

## Reine Umfrage (kein Themen-Pitch gewünscht)

Hauptnav-Kachel **"Umfragen"** → startet die Umfrage-Schritte direkt,
ohne Willkommens-Screen, für Situationen, in denen nur die Meinung
erfasst werden soll.
